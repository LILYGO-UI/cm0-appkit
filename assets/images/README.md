# Status Bar Image Assets

The Ethernet, keyboard, and Wi-Fi status icons are rasterized application
assets. Ethernet and keyboard use the Lucide icon set, which is distributed
under its project license:
https://github.com/lucide-icons/lucide/blob/main/LICENSE

The `src/icons/` C files contain 21-pixel ARGB8888 LVGL image data used by the
shared AppKit status bar.
